05 // WHAT IS REAL

Measured, not promised

REAL IN THE DEMO

The Midgard console talks to the actual Rust enclosure edge running in a container. The signed login token, the per-object marking checks, the human-gated action, the policy dry-run and every audit row are genuine.

SAMPLE DATA IN THE DEMO

The Forge, Mimir, Heimdall, Bifrost, Admin and client-shell consoles are the shipping builds on their built-in sample data. Their services do not expose console routes yet.

RELEASE STATUS

Version 0.1.0-rc.1 is a release candidate, not a supported release. General availability is gated on HSM key custody, GPU serving, FIPS 140-3 certification and a key ceremony. The deck's “Where we are” slide names every blocker.
