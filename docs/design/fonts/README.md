# Fonts

The design system's three typefaces, self-hosted so these pages render their own
type with no network. `../tokens/fonts.css` declares them. They are
byte-identical copies of `ui/design-system/src/fonts`, kept here so this tree
stays standalone. That directory's README records each file's source and
sha256; keep the two in step.

| File | Family | Weight axis | Licence |
|---|---|---|---|
| `Oxanium.ttf` | Oxanium | 200–800 | `Oxanium-OFL.txt` (OFL-1.1) |
| `SpaceGrotesk.ttf` | Space Grotesk | 300–700 | `SpaceGrotesk-OFL.txt` (OFL-1.1) |
| `JetBrainsMono.ttf` | JetBrains Mono | 100–800 | `JetBrainsMono-OFL.txt` (OFL-1.1) |
