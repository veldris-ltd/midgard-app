# Midgard Console UI kit

Proposed design (greenfield, no product UI exists) for the enclosure admin console: object fabric explorer with type registry table, live audit lineage, and an inspector rail. Derived from SAD_00 §6–8 (Object Fabric service, entity catalogue, governance & audit).

`index.html` is interactive: side-nav, tabs, selectable object rows driving the inspector. Composes the shared components via `_ds_bundle.js` under the `.theme-midgard` scope.
