# Forge UI kit

Proposed design (greenfield) for the data-operations console: pipeline DAG canvas (sources → transforms → dataset → object projection), build log terminal with animated build run, git-style version history, expectations health, and a governed Mimir transform suggestion. Derived from SAD_01 (FR-F-1..6).

Interactive: select DAG nodes, run a build (log streams), theme scope `.theme-forge` (ember accent).
