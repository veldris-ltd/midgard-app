# Heimdall UI kit

Proposed design (greenfield) for the operational-fusion console: common operating picture (synthetic blueprint canvas with range rings, layer toggles, PQ-authenticated feed status), entity tracking with classification confidence, and Mimir-generated ranked options behind a mandatory human authorisation gate. Derived from SAD_04 (FR-H-1..5).

Interactive: toggle layers, select entities, choose an option, authorise. Theme scope `.theme-heimdall` (watchman gold). The map is abstract by design; no real geography or imagery.
