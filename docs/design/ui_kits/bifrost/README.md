# Bifrost UI kit

Proposed design (greenfield) for the continuous-delivery console: staged ring rollout with animated promotion, fleet table, supply-chain verification terminal (reproducible build + SBOM + ML-DSA), offline bundles for air-gapped sites, and advisory Mimir release-risk panel. Derived from SAD_03 (FR-B-1..6).

Interactive: "Promote to Ring 2" animates the rollout bar; selectable fleet rows. Theme scope `.theme-bifrost` (bridge violet).
