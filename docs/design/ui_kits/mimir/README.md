# Mimir UI kit

Proposed design (greenfield) for the local agentic AI console: agent list with Evals scores, OAG-grounded chat with live object citations and a human-gated action card, guardrail status, self-* loop summary, model-family selector (Mistral / Nemotron / Gemma / Granite). Derived from SAD_02 (FR-MI-1..8).

Interactive: pick agents, send a message (canned grounded reply), authorise the gated action. Theme scope `.theme-mimir` (well teal).
