Install sheet · Mac · version 1.0

Installing Midgard

A demonstration of the Midgard suite (Midgard, Heimdall, Mimir, Forge) that runs entirely on your Mac: no internet, nothing else to install.

What you need

macOS 13.3
(Ventura) or later. Apple menu › About This Mac shows yours.
8 GB memory
or more, shown as Memory in About This Mac.
4 GB free
disk space, about: 1.6 GB for the app plus the .dmg file.
Any Mac
Apple silicon or Intel. Plus the file Midgard-1.0.dmg and your Mac password.

Install it (once per Mac)

  1. Double-click Midgard-1.0.dmg.

    macOS may show Verifying “Midgard-1.0.dmg”… with a progress bar for a minute or more: wait. Then a window opens with three items: Midgard, an Applications folder and this sheet.

  2. Drag the Midgard icon onto the Applications folder.

    Don’t open Midgard from this window; drag it to Applications first. Wait for the copy to finish (about a minute).

  3. Open your Applications folder and double-click Midgard.

    In the Finder: Go › Applications. The first time, macOS checks the app (it holds a 1.5 GB AI model): a Verifying “Midgard”… progress bar may show for a minute or more, longer on an older Intel Mac. Wait.

  4. macOS says it can’t verify Midgard. That is expected.

    Click Done (macOS 15 Sequoia, macOS 26 Tahoe) or Cancel / OK (macOS 13, 14). Not Move to Trash.

    macOS 15 and 26 show “Midgard” Not Opened: Apple could not verify “Midgard” is free of malware… Earlier versions say Apple cannot check it. Midgard doesn’t come from the App Store, so Apple hasn’t checked it.

  5. Open Apple menu › System Settings › Privacy & Security, then click Open Anyway.

    Scroll down to the Security section. Next to the line saying “Midgard” was blocked, click Open Anyway. When asked, enter your Mac password (an administrator’s) and click Open Anyway (or Open).

    The button stays for about an hour after step 4. If it isn’t there, repeat step 3 and come straight back.

  6. Midgard opens.

    macOS may check it again briefly. If Midgard doesn’t open by itself, double-click it in Applications again.

From now on open Midgard from Applications (or Launchpad / Apps) like any other app, with no more warnings. You can eject the Midgard disk (the eject button beside it in the Finder sidebar). To pass it on: send the .dmg file itself; don’t zip it or copy Midgard.app out.

Using Midgard

Starting Midgard…
Each time Midgard starts: about 10 seconds on an Apple silicon Mac, up to 40 seconds on an Intel Mac.
Home screen
Four tiles: Midgard, Heimdall, Mimir and Forge. Click one to open it; the menu at the top of the window switches product.
Presenter’s guide
Below the tiles: questions to ask Mimir and alerts to show in Heimdall, with answers prepared so they appear straight away. Your own questions are answered live, which takes longer (much longer on an Intel Mac).
Reset demo…
Top right of the window. Puts all the data back as it started; use it between audiences.
Quit
Midgard menu › Quit Midgard, or Command-Q. Everything Midgard started stops with it.

If something goes wrong

“The disk image couldn’t be opened” or it is damaged
The file was damaged on its way to you. Download Midgard-1.0.dmg again.
“Midgard is damaged and can’t be opened”
Move Midgard to the Trash, download Midgard-1.0.dmg again and install from it by double-clicking; don’t use another unzip or copy tool.
No Open Anyway button
Repeat step 3, then go straight back to Privacy & Security.
Needs an administrator, or no Open Anyway on a work Mac
Ask your IT team to allow Midgard.
Midgard says it needs macOS 13.3 or 8 GB
This Mac can’t run it. Use another Mac.
A message that something has stopped, or slow
Click Reset demo…, or quit Midgard and open it again. Quit other large apps (many browser tabs, video calls).
