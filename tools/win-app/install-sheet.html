Install sheet · Windows · version 1.0

Installing Midgard on Windows

A demonstration of the Midgard suite (Midgard, Heimdall, Mimir, Forge) that runs entirely on your PC: no internet, nothing else to install, no administrator needed.

What you need

Windows 11
64-bit, on an Intel or AMD processor. Not Windows 10, not an ARM PC, not S mode.
8 GB memory
or more. Settings › System › About shows it as Installed RAM.
6 GB free
disk space, about: for the ZIP file, Midgard itself and its data.
The ZIP file
Midgard-1.0-Windows.zip, copied onto the PC (for example in Downloads).

Install it (once per PC)

  1. Right-click Midgard-1.0-Windows.zip and choose Extract All…

    Click Browse… and choose a short place such as Documents, then Extract. Wait for it to finish (a few minutes).

    Don’t open Midgard from inside the ZIP (double-clicking the ZIP only shows what is inside it).

  2. Open the Midgard folder and double-click Midgard.

    For example Documents › Midgard. Midgard is the app with the Midgard icon.

  3. “Windows protected your PC”: click More info, then Run anyway.

    The blue box appears because Midgard isn’t from the Microsoft Store. Not Don’t run. If a box says the publisher could not be verified, click Run.

  4. Midgard opens and shows Starting Midgard…

    The first start can take a few minutes while your antivirus checks Midgard’s files. Then Midgard asks once:

    Add Midgard to the Start menu? You can then open it from Start like any other app. Click Yes (recommended) or No.

From now on open Midgard from the Start menu, or double-click Midgard in its folder. Keep the Midgard folder where it is (the Start menu entry points to it). To pass it on: send the ZIP file itself, not the extracted folder.

Using Midgard

Starting Midgard…
Shown each time it starts, with each part’s progress; longer on the first start and on slower laptops.
Home screen
Four tiles: Midgard, Heimdall, Mimir and Forge. Click one to open it; the menu at the top of the page switches product. Home on the toolbar comes back here.
Presenter’s guide
Below the tiles: questions to ask Mimir and alerts to show in Heimdall, with answers prepared so they appear straight away. Your own questions are answered live, which takes longer.
Reset demo…
On the toolbar. Puts all the data back as it started (about a minute); use it between audiences.
Quit
Quit on the toolbar, or close the window. Everything Midgard started stops with it.
Removing it
Quit Midgard and delete the Midgard folder. Then type %LOCALAPPDATA% in File Explorer’s address bar, press Enter, and delete the Midgard folder there too (the demo’s data). If you added it to Start, right-click Midgard in Start › Open file location and delete the shortcut.

If something goes wrong

“Midgard needs Windows 11”, “an Intel or AMD (x64) processor” or “8 GB of memory”
This PC can’t run it (Windows 10, an ARM PC, too little memory). Use another PC.
“…at least 4 GB of free disk space”
Empty the Recycle Bin or delete old files, then open Midgard again.
“…needs the Microsoft Edge WebView2 Runtime”
Run Windows Update (Settings › Windows Update), restart, try again.
“This Windows edition lacks the Media Feature Pack”
A Windows “N” edition: only camera clips can’t play. Add the Media Feature Pack (search Start for Optional features).
Windows 11 in S mode
Not supported (it runs only Store apps). Use another PC.
A live Mimir answer takes minutes
Normal on a laptop. The Presenter’s guide questions answer instantly.
A work PC blocks Midgard, or no Run anyway
PCs managed by IT may block unsigned apps. Ask your IT team.
“Path too long” while extracting, or something stopped
Extract to a short place such as Documents. Otherwise Reset demo…, or quit and reopen.
